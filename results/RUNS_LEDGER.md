## What a set is

One base seed, 500 runs. Run k draws its seed from the jump generator, seed_k = base + k·0x9E3779B9 mod 2³², and feeds a mulberry32 stream through the mechanism. Three implementations run the same set and each writes one SHA-256 digest of its receipts (every number at six decimals, one line a run): **the Python** (`tools/engine_runs.py`: 288 decisions of the brain by RK4, 80 steps of the compass law, one give-back trial judged by the verdict; `tools/core_runs.py`: the core's Monte Carlo, four ways), **the C++ harness** (`cpp/tools/engine_runs.cpp`, `cpp/tools/core_runs.cpp`, the engine's C++ twins, fed the Python's draws) and **the live engine page's own code** (its ported engine and loop, run in node on GitHub and in the reader's browser). The three digests must be one, at the whole set and at its first 1, 10 and 100 runs (the ladder).
